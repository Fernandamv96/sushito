# Sushito

Landing page para una sushería ficticia, **Sushito**. Tiene un hero con el sushi separado en capas que se arma al cargar y se desarma al hacer scroll, una sección de piezas que entran tomadas con palillos y un menú destacado.

Hecha con HTML, CSS y JavaScript, sin build. Las animaciones usan [GSAP](https://gsap.com/) y ScrollTrigger desde CDN.

## Ver en local

Abre `index.html` en el navegador o usa un servidor estático, por ejemplo la extensión Live Server de VS Code.

## Estructura

```
index.html   estructura de la página
style.css    estilos y diseño responsive
script.js    animaciones (entrada, flotación, scroll y parallax)
img/         fotos con fondo transparente (capas del hero, piezas y platos)
```

## Créditos de imágenes

Las fotos de sushi son material de referencia para un proyecto de estudio. Antes de un uso comercial hay que verificar su licencia o reemplazarlas.
